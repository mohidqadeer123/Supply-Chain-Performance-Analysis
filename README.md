# Supply-Chain-Performance-Analysis

## Overview
The Supply Chain Performance Dashboard is a data analytics project designed to improve operational visibility across key supply chain processes. The project integrates data from multiple operational sources, applies structured data preparation workflows, and delivers interactive analytics through a business intelligence dashboard. The goal is to support data-driven decision-making for inventory management, procurement efficiency, and operational performance monitoring.

## Objectives
- Consolidate supply chain data from multiple sources
- Enable real-time KPI monitoring across inventory and procurement operations
- Support better decision-making for reorder point and safety stock planning
- Improve visibility into work-in-progress (WIP) and execution metrics

## Data Collection and Preparation
Supply chain data was gathered from multiple operational sources and processed using Excel and SQL. A structured ETL workflow was developed to:
- Clean and standardize datasets
- Integrate multiple data sources
- Organize data into structured tables suitable for analysis
- Prepare datasets for real-time KPI tracking

Key supply chain metrics prepared during this stage include:
- Reorder point calculations
- Safety stock evaluation
- Inventory category performance

## Dashboard Development
An interactive dashboard was built in Power BI using DAX measures to visualize operational performance across supply chain functions.

The dashboard includes:
- Inventory turnover analysis
- Procurement performance metrics
- Work-in-progress (WIP) tracking
- Operational execution KPIs

These visualizations enable stakeholders to quickly identify trends, inefficiencies, and potential supply chain risks.

## Key Features
- Interactive filters and drill-down capabilities
- Real-time KPI monitoring
- Category-level inventory insights
- Procurement and execution performance tracking

## Documentation and Maintainability
All data sources, transformation steps, assumptions, and dashboard logic were documented to ensure:
- Transparency in analytical methodology
- Ease of future updates and maintenance
- Long-term reporting sustainability across operational data sources

## Impact
The dashboard enhances operational visibility by consolidating supply chain performance indicators into a single analytical platform, enabling leadership teams to make informed decisions regarding inventory optimization, procurement planning, and supply chain efficiency.
